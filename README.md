# Bakery Billing & Management System

A command-line interface (CLI) application built in Python for automating bakery sales and inventory management.

## Features
- Security: Password hashing with SHA-256.
- Inventory Management: Full CRUD operations via SQLite database.
- Billing Engine: Itemized calculations with formatted receipt generation.

## Requirements
- Python 3.8+

2. Navigate to project root directory:
